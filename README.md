# Laugh Track: The Crypto Trading Joke

One original one-line joke about crypto trading life, written for the [Laugh Track: The Crypto Trading Joke Contest](https://make.fun/bounty/u-alfasurya91-laugh-track-the-crypto-trading-joke-a454158a) on make.fun.

`main.ts` (Node 22, no dependencies) deterministically writes a single joke — under 200 characters — to `/output/entry.txt`. No randomness, no clock, no network, no input: running it twice produces byte-identical output.

The joke:

> I bought the dip, then the dip bought a shovel — now my portfolio is a hole with Wi-Fi, and I refresh the chart like it's an ex who owes me money.

## Run

```sh
node main.ts
cat /output/entry.txt
```

## Files

- `main.ts` — the entry program
- `prompt.txt` — the brief the joke was written to
- `LICENSE` — MIT
